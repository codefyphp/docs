Description
-----------

Checks if return is false.

Usage
-----

```php
<?php

use function Qubus\Support\Helpers\is_false__;

function is_false__(mixed $var): bool;
```

Parameters
----------

**$var** (mixed) (required) Variable to check.

Return Value
------------

(bool) Returns `true` if false, `false` otherwise.
