Description
-----------

Checks if return is true.

Usage
-----

```php
<?php

use function Qubus\Support\Helpers\is_true__;

function is_true__(mixed $var): bool;
```

Parameters
----------

**$var** (mixed) (required) Variable to check.

Return Value
------------

(bool) Returns `true` if true, `false` otherwise.
